# Demo prompts

下面的 prompts 用于生成 README 中的三张示例图。它们展示的是“先抓住一个认知锚点，再发明一个物理隐喻”，不是固定模板。

## 1. 内容入口实验

```text
Use $xiao-gecko-illustrations 生成一张 16:9 横版正文配图。

主题：本周内容实验要同时优化小红书封面点击率和抖音前 2 秒留存，并找到下周可以复制的结构，同时记录制作时间。
隐喻：小 gecko 正在拧开一扇内容入口的两道门闩，上面标“封面 15%”，下面标“前2秒 <30%”；门后只有“可复制”和“制作时间”两个短标注。
要求：纯白背景、黑色手绘线稿、大量留白、少量红橙蓝手写批注，小 gecko 必须做核心动作，不要 PPT 感。
```

## 2. 从功能堆到用户结果

```text
Use $xiao-gecko-illustrations 为“产品不是功能堆，而是让用户更快到达一个结果”生成一张正文配图。
只保留两个标注：“功能堆”和“用户结果”。让小 gecko 用一个奇怪但成立的低科技动作，削掉多余功能并搭出一条清晰路径。
```

## 3. 发布到反馈回流

```text
Use $xiao-gecko-illustrations 为“内容发出去不是结束，反馈要回到下一条内容里”生成一张正文配图。
只保留三个标注：“发布”“反馈”“下一条”。不要使用传送带、素材鱼或正式流程图；让小 gecko 参与一个新的手绘低科技隐喻。
```
