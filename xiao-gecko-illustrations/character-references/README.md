# 项目角色参考

这里保存项目中可以在确认方案里显式选择的角色参考。角色名称与参考图必须一一对应，不得混用外观特征。

## 小睫毛

- 参考图：`../assets/gecko-reference.png`
- 角色名：小睫毛
- 稳定识别点：奶油白身体、浅棕斑纹、深色大圆眼、头部尖耳/鳞片轮廓、细小四肢、长尾巴
- 默认关系：未提供 `characters` 时使用；用户明确选择两个形象时，作为本次任务的第一角色

## 小溪流

- 参考图：`xiaoxiliu-reference.png`
- 角色名：小溪流
- 稳定识别点：灰白身体、橙色斑点、金色竖瞳、宽嘴、细小四肢、长尾巴
- 默认关系：不会自动加入小睫毛；只有用户或确认方案明确选择时使用
