# 风格 DNA

## 一句话

纯白、极简、手绘、留白、克制、怪诞、产品草图感、中文手写感；像一个长期做产品、AI 和生意的人在白纸上画出的解释草图。

## 必须

- 4:3 横版 1080p 正文配图，尺寸为 1440×1080。
- 纯白背景：不要米色、暖灰、纸张纹理、渐变、阴影、噪点或复古纸感。
- 黑色/深棕色手绘线稿，细线、轻微抖动、不机械、不厚重描边。
- 主体约占画面 40%-60%，至少保留 35% 空白，最好留一整块安静区域。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 中文手写批注最多 5-8 处，每处尽量 2-8 个字。

## 颜色

- 黑色/深棕色：默认小睫毛或用户提供角色的轮廓、主要线稿、结构、主要文字。
- 橙色：主流程、路径、箭头、自动化流向。
- 红色：重点批注、问题、情绪点、关键提醒、结果。
- 蓝色：补充说明、脑内状态、系统状态、AI/assistant 提示。

颜色要克制，宁可少不要多。蓝色不是每张都必须使用。

## 绝对不要

- 商业插画、PPT 信息图、正式流程图、课程课件或科技 UI。
- 可爱卡通海报、儿童插画、精致扁平插画、复杂架构图。
- 复杂背景、渐变、阴影、纹理、真实 App 截图。
- 左上角出现“Workflow 流程图 / 系统架构图 / 常见坑 / 路线图”等类型标题。
- 把所有节点都解释清楚，或把正文改成大段图中文字。
